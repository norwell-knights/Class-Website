Software Development

Course Description

SDEV 140 — Introduction to Software Development prepares students to design, implement, and test software solutions using modern programming practices. The course emphasizes problem solving, structured programming, and software design principles using Python. Topics include control structures, functions, basic data structures, debugging, version control, and introductory object-oriented programming. Additional class work explores building graphical interfaces with Tkinter, developing simple web applications with Django, and consuming/creating RESTful APIs.

High School Credits and CTE Pathway

7184 Software Development is the second semester, second-year course in the Software Development CTE Pathway. It builds on entry-level computing skills and prepares students for capstone experiences and industry certifications. The course counts toward the Software Development Pathway and elective credits for graduation.

College Credit

Dual-credit through Ivy Tech is available for SDEV 140 — Introduction to Software Development (3 credit hours). Course content aligns with hands-on programming, software engineering basics, and practical application development.

Major Learning Objectives

Students completing SDEV 140 will be able to:

  • Apply structured problem-solving techniques to design algorithms and translate them into working Python programs.
  • Use control structures, functions, and basic data structures (lists, tuples, dictionaries) to build modular code.
  • Demonstrate introductory object-oriented concepts (classes, objects, methods) and use them to model simple systems.
  • Read, write, and debug Python code using developer tools and testing approaches to identify and fix defects.
  • Use version control (Git) for code management and collaborative development workflows.
  • Build simple graphical user interfaces with Tkinter and understand event-driven programming concepts.
  • Create basic web applications using Django, including routing, templates, and simple persistence.
  • Design and interact with RESTful APIs using Python (requests, Flask/Django REST patterns) for data exchange.
  • Understand how to connect applications to data stores and perform basic data handling and validation.

Student Projects

Course projects emphasize applied learning: console applications that solve real problems, GUI tools built with Tkinter, small Django web apps, and API-driven mini-projects. Students are encouraged to publish portfolio-ready work that demonstrates code quality, testing, and clear documentation.
