Capstone Courses

Course Description

Capstone Courses provide advanced, project-driven experiences where students apply software development practices to real-world problems. These courses focus on integrating design, implementation, testing, and deployment while emphasizing teamwork, documentation, and professional presentation. Topics vary by offering and may include game development, advanced Python programming, hybrid mobile frameworks, and introductory machine learning.

Capstone Offerings

Students select from rotating capstone topics that allow deeper exploration and portfolio development. Example offerings include:

  • SDEV 148 — Game Development with Godot
  • SDEV 220 — Programming in Python (advanced topics)
  • Hybrid App Frameworks (React Native / Cordova)
  • Machine Learning Foundations and Applications

High School Credits and Pathway

Capstone courses are designed for Years 3+ of the Software Development pathway. These classes round out the pathway and give students opportunities to create portfolio-ready projects, pursue internships, and prepare for postsecondary study or employment. Depending on future funding students might be able to earn 6 credit hours for the capstone courses through Ivy Tech.

Major Learning Objectives

  • Plan and execute a substantial software project from requirements through deployment.
  • Collaborate effectively in teams using version control and agile workflows.
  • Apply software testing, debugging, and quality assurance practices.
  • Communicate technical work through documentation, presentations, and demos.
  • Explore advanced topics such as game engines, mobile frameworks, and machine learning.
  • Prepare a professional portfolio showcasing project artifacts, source code, and deployment links.

Student Outcomes

Students leave Capstone Courses with polished projects suitable for college applications or employer review, experience working in collaborative development environments, and exposure to advanced tools and frameworks used in industry.
