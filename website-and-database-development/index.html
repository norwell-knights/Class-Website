Website and Database Development

Course Description

Website and Database Development builds on foundational computing skills and focuses on designing, building, and deploying web applications and managing data. Students learn modern front-end technologies (HTML, CSS, responsive design, accessibility), client-side scripting with JavaScript, and practical workflows for creating maintainable websites. The course also introduces relational database concepts, data modeling, and basic data analysis techniques used to store, query, and visualize information.

High School Credits and CTE Pathway

7185 Website and Database Development is part of the Software Development CTE Pathway. This course typically follows Principles of Computing and precedes advanced software development and capstone experiences. It counts toward elective and pathway credits for graduation.

College Credit

Dual-credit options through Ivy Tech include SDEV 153 — Website Development (3 credit hours) and DBMS 110 — Introduction to Data Analytics (3 credit hours).

Learning Objectives

The outcomes below reflect the practical skills and concepts students will master, aligned with Ivy Tech's SDEV 153 and DBMS 110 learning goals.

SDEV 153 — Website Development

  • Structure web pages with semantic HTML5 and organize site content effectively.
  • Style and layout pages using CSS, including responsive design techniques for multiple screen sizes.
  • Implement client-side interactivity using JavaScript (DOM manipulation, event handling, form validation).
  • Apply accessibility best practices and use developer tools to debug and optimize front-end code.

DBMS 110 — Introduction to Data Analytics (selected objectives)

  • Explain relational database concepts and design simple entity-relationship models.
  • Write basic SQL queries to select, filter, sort, and aggregate data.
  • Perform joins and use grouping/aggregation to answer practical data questions.
  • Understand data normalization and apply basic techniques to reduce redundancy.
  • Create simple full stack website using SQL and PHP on the backend.

Student Projects

Students apply learned skills by building portfolio-style projects: multi-page websites, interactive web apps, and data reports driven by SQL queries. Projects emphasize maintainable code, usability, and real-world data handling.
